# Focus Blocker 網頁限制器

Focus Blocker 是一個為 Google Chrome 設計的防沉迷擴充功能。它透過**「強制全螢幕等待」**與**「全域階梯式等待時間」**的機制，在你衝動想存取受限制的網站（或修改設定）時製造阻力，幫助你重新找回專注力。

## 🌟 主要功能

- **🕒 碎片化限制時段**：支援設定多組「受限制時段」（例如：09:00~12:00 以及 13:00~18:00）。
- **⏳ 全域階梯式等待機制**：
  - 在限制時段內，任何嘗試解鎖受限網站，或是進入「設定頁面」的行為，都需要經過強制等待。
  - 等待時間採**全域累積制**：第一次等待 2 分鐘，第二次 3 分鐘，以此類推。每日重置。
- **🛡️ 嚴格的防作弊全螢幕機制**：
  - 必須點擊畫面任意處進入**全螢幕**，計時器才會開始倒數。
  - 倒數期間若按 `Esc` 退出全螢幕、切換分頁或縮小視窗，計時器將會立刻隱藏並重置，絕不妥協！
- **🔓 全域短期解鎖**：
  - 撐過等待時間後，可自由選擇本次解鎖時長（5、10 或 15 分鐘）。
  - 在解鎖期間內，所有受限網站與設定頁面皆可自由通行；時間一到，限制會立刻全面恢復。

## 📥 安裝與載入教學

由於本擴充功能未上架 Chrome 線上應用程式商店，請依照以下步驟手動載入至您的瀏覽器：

### 1. 準備檔案
請確認您已下載本專案的完整資料夾，其中至少包含以下核心檔案：
- `manifest.json` (擴充功能設定檔)
- `background.js` (背景邏輯服務)
- `options.html` / `options.js` / `options.css` (設定頁面介面與邏輯)
- `block.html` / `block.js` / `block.css` (攔截等待畫面與防作弊邏輯)

### 2. 載入至 Chrome
1. 開啟 Google Chrome 瀏覽器。
2. 在網址列輸入 `chrome://extensions/` 並按下 Enter 進入「擴充功能」管理頁面。
3. 開啟頁面右上角的 **「開發人員模式」 (Developer mode)** 開關。
4. 點擊頁面左上角的 **「載入未封裝項目」 (Load unpacked)** 按鈕。
5. 在選擇視窗中，選擇本專案所在的資料夾，然後點擊確認。
6. 安裝成功！您應該會看到 **Focus Blocker** 出現在擴充功能清單中。

### 3. 開始使用
1. 點擊瀏覽器右上角的「拼圖圖示」，將 Focus Blocker 釘選 (Pin) 到工具列，方便隨時存取。
2. 點擊工具列上 Focus Blocker 的圖示，會直接為您開啟設定頁面（若在限制時段內，則需先通過等待考驗才能進入）。
3. 新增您想封鎖的網站（如 `youtube.com`）並設定限制時段。
4. 設定完成後，開始享受不被打擾的專注時光吧！
