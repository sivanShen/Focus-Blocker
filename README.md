# Focus Blocker (Desktop App Edition)

Focus Blocker 是一個專為防止分心所設計的「企業級」強迫專注軟體。它由兩個核心部分組成：一個在電腦背景強制運行的 **桌面版應用程式 (Desktop App)**，以及一個受到完全管控的 **Chrome 瀏覽器擴充功能 (Drone Extension)**。

這套系統完美模仿了手機版防分心 App（如 Opal）的硬核機制：在限制時段內，您**絕對無法**輕易更改設定或關閉防護。想解鎖？唯一的方法就是乖乖打開主程式，看著全螢幕的倒數計時器跑完！

## ✨ 核心功能與特色

### 1. 雙重防護網 (App & Web Blocking)
*   **電腦軟體封鎖**：您可以設定黑名單（例如 `LeagueClient.exe`, `Discord.exe`），只要在限制時段內開啟這些軟體，Focus Blocker 會在 1 秒內強制將其關閉。
*   **網頁網域封鎖**：配合 Chrome 擴充功能，精準攔截分心網站（例如 `youtube.com`）。

### 2. 硬核防作弊等待機制 (Opal-like Anti-Cheat)
*   **霸王級全螢幕**：在限制時段內想修改設定？主程式會強制彈出一個無邊框、無法縮小、無法用 `Alt+F4` 關閉的全螢幕深呼吸畫面。
*   **階梯式等待懲罰**：想要解除限制，必須付出時間代價。第一層等待 20 秒，第二次 40 秒，第三次 80 秒...（每次遞增 20 秒的等待時間），一天內越想解除限制，需要等待的時間就越長（每日半夜自動歸零）。

### 3. 機構級強制鎖死 (Enterprise Registry Lock)
*   這是本系統的終極防禦。透過修改 Windows 登錄檔 (Registry)，Chrome 擴充功能將會被標記為「由您的機構管理」。這意味著即使您打開瀏覽器的擴充功能管理介面，**您也無法將其停用或移除（按鈕會被反灰鎖死）**。

## 📥 安裝與啟動教學

本系統分為兩階段安裝：**啟動桌面主程式** 與 **鎖死瀏覽器擴充功能**。

### 第一階段：啟動桌面主程式 (Desktop App)
1. 請確認您的電腦已經安裝 [Node.js](https://nodejs.org/)。
2. 下載或 Clone 此專案。
3. 開啟終端機 (PowerShell 或命令提示字元)，進入 `desktop_app` 資料夾：
   ```bash
   cd chrome_blocker/desktop_app
   ```
4. 安裝必要套件：
   ```bash
   npm install
   ```
5. 啟動開發者模式（或者您可以自行執行 `npm run build` 打包成獨立的 `.exe` 檔）：
   ```bash
   npm start
   ```
   > 啟動後，桌面版設定介面會自動彈出，並且常駐在 Windows 右下角工作列系統匣中。

### 第二階段：載入並鎖定 Chrome 擴充功能
擴充功能（位於根目錄 `chrome_blocker/`）現在只是一個「探測器」，完全聽從桌面端 App 的指令。

1. 開啟 Chrome 瀏覽器，前往 `chrome://extensions/`。
2. 開啟右上角的「開發人員模式」。
3. 點擊「載入未封裝項目」，選擇根目錄 `chrome_blocker`。
4. **【重要】複製該擴充功能卡片上的「ID」**（例如 `abcdefghijklmnop...`）。
5. 回到 **桌面版設定介面**，在最上方的「瀏覽器擴充功能防護」區塊中，貼上這個 ID 並點擊新增。
6. 系統會提供一串 PowerShell 腳本。請**以系統管理員身分 (Run as Administrator)** 開啟 PowerShell，將指令貼上並執行。
   *(或者，您也可以直接在 `desktop_app` 資料夾內找到 `LockExtension.ps1`，對它點選右鍵 > 選擇「以 PowerShell 執行」)*
7. 執行完畢後，**重新啟動 Chrome 瀏覽器**。此時擴充功能已被強制鎖定。

## 🛠️ 如何使用？
1. **設定限制時段**：在桌面版設定中，加入您想要專注的時間（例如 09:00 - 18:00）。
2. **新增受限目標**：在設定中加入您想封鎖的軟體（如 `Spotify.exe`）或網站（如 `facebook.com`）。
3. **享受專注**：時間一到，所有受限網站與軟體將全面失效。如果您受不了想解除限制，請點擊右下角系統匣的 Focus Blocker 圖示，乖乖盯著全螢幕的倒數沙漏，深呼吸，思考一下這是否真的值得。
